# Заметки по Git
Эксперимент А. Пустая папка

Вопрос 1: Почему папка не появляется в репозитории?
Ответ: Git не отслеживает пустые папки. Git хранит только файлы. Папка — это просто контейнер для файлов. Если внутри папки нет ни одного файла, Git считает, что там нечего хранить.

Вопрос 2: Что Git на самом деле хранит — файлы или папки?
Ответ: Git хранит файлы. Папки (директории) Git не хранит как отдельные объекты. Информация о папках появляется только тогда, когда внутри есть файлы.

Как я добился, чтобы папка попала в репозиторий:
Я создал внутри папки sandbox пустой файл .gitkeep. Git увидел этот файл и добавил его в репозиторий. Вместе с файлом в репозитории появилась и информация о папке.
